Rules

  • 2×5 should feel like a 2nd or 3rd warmup set
  • Never miss a rep
  • Never grind
  • If yesterday felt hard, go lighter
  • Add weight only when it feels light
  • Use rest time for easy mobility
  • Fat loss comes from diet
  • After workout 40: reassess, then run another 40 with new close variations or move to a hypertrophy block

Before you start

  • Warmup: 5 min walk/row + 1 light set of the first lift
  • Load: start ~50–60% of old weights
  • Effort: leave 2–3 reps in the tank
  • Rest: ~60–75 sec between sets
  • Optional cardio after lifts — keep lifts ≤ 30 min
